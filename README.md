# CLIProxyAPI Clean Management Panel

This is a generated, single-file management panel based on the latest stable release of
[`router-for-me/Cli-Proxy-API-Management-Center`](https://github.com/router-for-me/Cli-Proxy-API-Management-Center).

The clean build changes presentation only:

- hides the APIKEY.FUN quick-start promotion;
- hides sponsored/affiliate provider shortcuts;
- hides the proxy sponsor link;
- keeps OAuth, provider configuration, quota, logs, plugins, plugin store, and system pages.

The workflow checks the latest official release every day. When a new release appears, it builds
and publishes a new GitHub Release containing `management.html`. It fails safely if the relevant
upstream source structure changes instead of publishing an unreviewed or partially cleaned build.

The upstream source remains subject to its original license. See the upstream repository for
source code, license terms, and project documentation.
